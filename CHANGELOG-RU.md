# История изменений

[English](CHANGELOG.md) · **Русский**

Версия задаётся в одном месте — `ShadowTrimPlugin.Version` в `src/ShadowTrimPlugin.cs`.

## 0.1.0

- Первый выпуск. Дальность тени по слоям у солнца игры: детали построек 60 м, детали, сквозь
  которые можно пройти, 40 м, мелкие объекты 30 м, выпавшие предметы 25 м (в игре — 120 м);
  любой другой слой — через `OtherLayers`.
- Плоские детали на земле (полы, плиты дорожек, ковры) не отбрасывают тень; каждая деталь
  осматривается один раз после загрузки, не больше 1 мс за кадр.
- `Preset`: `Normal`, `Low` для слабых ПК, `Custom`.
- Консоль: `shadowtrim` (вкл / выкл), `shadowtrim status`, `shadowtrim bench`.
